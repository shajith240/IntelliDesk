Admin Operations

Everything a workspace admin does, in the order they'd do it when setting up, with the screens, the API calls, the validations, what gets audited, and the errors they can see.

Setting up the workspace

What does an admin do on day one?Basic
  1. Settings → Support mailbox: connect Gmail (or another provider).
  2. Settings → AI: paste the company's Gemini API key (or rely on the platform key); leave automatic replies off at first.
  3. Knowledge Base: add the most common questions and answers — the AI only drafts from these.
  4. Settings → Members: add agents and viewers; hand each their one-time password.
  5. From then on: the Needs Review queue, assigning, the Spam page and the Command Center.

How does connecting Gmail work?Intermediate

The Gmail tab is a three-step guide: turn on 2-Step Verification, create an app password (links open the exact Google pages), paste the address and the 16-letter password. "Verify and connect" posts to /api/settings/email-config, which performs a real IMAP login and SMTP handshake before saving anything. Wrong credentials produce an actionable message ("use a 16-character app password…"). On success the password is encrypted and the card shows the address, hosts, "Connected" and when it was last checked. Change mailbox / Reconnect reopen the form; Disconnect (with confirmation) deletes the row so the ciphertext doesn't linger. Audit: mailbox_connected, mailbox_disconnected.

The "Other provider" tab takes address, optional username, password, IMAP host (port 993 fixed) and SMTP host with port 465 or 587; hosts must resolve to public addresses.

How does the AI panel work?Intermediate

The panel shows which key the AI runs on: "Your key ···abcd" (healthy or "Needs attention" with the last error), "Shared platform key", or "Not configured" (email waits in the queue). Pasting a key and clicking Verify and save checks it with Google first; a rejected key saves nothing. Remove deletes it. The switch "Send confident answers automatically" is off by default and its description lists exactly when a reply may go out unreviewed. Audit: ai_key_saved, ai_key_removed, ai_auto_send_changed.

Team

How are members added?Basic

Add member asks for name, email and role (agent, viewer or admin). The server generates a random 16-character password, stores only its bcrypt hash, and returns the password once; the dialog shows it with a copy button (falling back to manual copy if clipboard access is blocked). The member signs in and changes it from the user menu. An email already in use returns 409. Audit: member_added.

src/features/settings/components/add-member-dialog.tsx:64-91; src/app/api/team/route.ts:48-109
How are roles changed and members deactivated?Intermediate

From the member's row menu. Deactivation opens a confirmation that explains their open tickets will return to the pool. The server refuses to let an admin demote or deactivate themselves and keeps at least one active admin. Deactivating or making someone a viewer releases their open tickets (recorded in assignment history with the reason). The member's session ends within 5 minutes. Audit: member_updated.

Daily work

How does the admin work the Needs Review queue?Basic

Needs Review lists open, unassigned tickets the AI flagged. Each row's menu has Assign to… with teammates ranked available first, then by open-ticket count (each shows its number of open tickets), plus Unassign. The same menu exists in the ticket workspace header. Assignment is atomic and audited (ticket_assigned/ticket_unassigned).

How is the Spam page used?Basic

It lists what the local filter or the AI classified as spam in the last 30 days (sender, subject, preview, time). Not spam sends the email back to the intake queue with an override so the filters don't catch it again; it becomes a ticket on the next mailbox check (within 10 minutes). Audit: email_marked_not_spam. Machine-generated mail (bounces, out-of-office) is not spam and never appears here: it's ignored before the spam filters run.

How is the knowledge base maintained?Intermediate

Admins create and edit articles (question, answer, category) in a dialog and delete them with confirmation; agents and viewers can read. Each article is embedded before it is saved (an AI outage saves nothing and shows "AI isn't set up / busy"), edits re-embed only when the text changed, and deleting an article also deletes its vector so the AI stops quoting it. Each card shows "Cited in N AI drafts", counted from the citations table. Search strips filter syntax before querying.

What do the Command Center and Analytics show?Basic

Command Center: a metric strip (open queue split into new / in progress / pending, highest-priority count, SLA breached, needs review, average AI confidence), the SLA risk panel, recent activity from the audit log, and the open work queue. Analytics: status breakdown across all five statuses, priority and category breakdowns, SLA averages. Viewers see the same; agents are redirected to My Work. "Today" figures use the workspace timezone.

How can emails be imported in bulk?Basic

POST /api/emails/bulk (admin) accepts up to 50 emails per call and runs each through the full pipeline with a pause between them to respect AI rate limits. It exists for migrating an existing inbox; there is no UI for it.
