IntelliDesk AI — Project Documentation

A support-operations app that ingests customer email, classifies and triages it with Gemini, tracks SLAs, and drafts replies for an agent to review and send. Built with Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4, NextAuth v5, Supabase (Postgres), Pinecone, and Google Gemini. This site is a set of grounded, citable Q&A pages over the actual codebase — every code excerpt and number is copied or measured directly from the real files, with a source path underneath.

How to use this site

What's the fastest way to get ready for an interview using this?Basic

Start with System Architecture for the shape of the thing, then Data Model & Schema and API & Backend Routes for the backend surface, then the two Walkthroughs to see how a real request moves through the whole system end to end. Decisions & Trade-offs and Bugs & Lessons are the pages most likely to map directly onto "tell me about a decision you made" or "tell me about a bug you fixed" interview questions — they were written first-hand by whoever made those changes, not reconstructed from a diff. Every page has a search box in the sidebar that filters its own Q&A items.

Can I trust every claim on this site?Basic

Every code excerpt is copied verbatim from a real file, with a src/path/to/file.ts citation underneath it. Where a feature doesn't exist — for example, there is currently no automated test suite — the relevant page says so explicitly rather than describing something aspirational as if it were built. If a claim on any page looks wrong, the fix is to open the cited file and check; that's the same standard these pages were held to while being written.

What the product does, in one flow

What's the single most important thing to be able to explain about this project?Intermediate

A customer email arrives (via IMAP poll or a webhook) → it's parsed, deduplicated by thread, and classified by Gemini into a category/priority/sentiment with a confidence score → a ticket is created, org-scoped to the sending domain's organization → if the email's content matches a knowledge-base article closely enough, Gemini drafts a reply and a candidate response is stored, unsent → an agent opens the ticket, sees the AI analysis clearly labeled as AI output (never presented as verified fact), edits the draft if needed, and explicitly confirms sending it → only then does the system email the customer and mark the ticket resolved. The full trace of this, file by file, is the Email → Ticket → AI Draft and Agent Reviews & Sends walkthrough pages.
